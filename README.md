# Cadastro de Pessoas (Java)

Meu primeiro projeto em Java, feito originalmente para uma A3 da faculdade.
Evoluí o código original para persistir os dados em arquivo, já que a versão
inicial perdia os cadastros ao fechar o programa.

## Funcionalidades
- Cadastrar pessoa (nome, CPF, celular, data de nascimento, sexo, CEP, email, senha)
- Listar pessoas cadastradas
- Excluir pessoa
- Dados salvos em arquivo CSV (pessoas.csv), mantidos entre execuções

## Tecnologias
- Java (Scanner, ArrayList, manipulação de arquivos)

## Como rodar
1. Clone o repositório
2. Abra no NetBeans, IntelliJ ou Eclipse
3. Rode a classe CodigoA3definitivo
